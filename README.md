# 📍 Autocompletar Endereço por CEP

Este projeto utiliza a **API ViaCEP** para preencher campos de endereço automaticamente em um formulário assim que o usuário digita um CEP válido.

![GIF de Demonstração](httpsd://camo.githubusercontent.com/48d132b5557713437c1d3c05c065f3f4c01d4a03429a8a79109f6e5218d6365a/68747470733a2f2f692e696d6775722e636f6d2f5a5078564f336a2e676966)

### Como usar?

1.  Clone este repositório: `git clone https://github.com/seu-usuario/nome-do-repositorio.git`
2.  Abra o arquivo `index.html` em seu navegador.
3.  Digite um CEP brasileiro de 8 dígitos no campo correspondente e veja a mágica acontecer!

### Tecnologias

-   HTML5
-   CSS3
-   JavaScript (com Fetch API)
-   [ViaCEP API](https://viacep.com.br/)
